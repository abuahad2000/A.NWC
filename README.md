## 🌟 مميزات المنصة

1. **📊 الاستيراد والتحليل الآلي لملفات الإكسيل (Excel Parser Engine):**
   - إمكانية رفع أي ملف إكسيل (`.xlsx` / `.xls`) عبر المتصفح مباشرة دون الحاجة لخوادم خلفية.
   - تطبيق خوارزمية الفلترة والحوكمة الصارمة تلقائياً (بوابات التحقق الأربع، ربط المقاولين، المطابقة المكانية).

2. **🗺️ الربط بخريطة مفتوحة المصدر (OpenStreetMap):**
   - دمج محرك الخرائط مفتوح المصدر عبر Leaflet.js بدون أي مفاتيح API أو قيود.
   - عرض المواقع الجغرافية الدقيقة للبلاغات مع إمكانية التكبير والنقر لعرض تفاصيل البلاغ والمقاول وأيام التأخير.

3. **⚡ إدارة تفاعلية متكاملة للبلاغات (CRUD Operations):**
   - **➕ إضافة بلاغ جديد:** نموذج إدخال متكامل مع التحقق من الحقول وربطه آلياً بكتالوج المشاريع الجارية.
   - **✏️ تعديل البلاغ:** تعديل بيانات البلاغ، المقاول، مدير البرنامج، والإحداثيات.
   - **✅ تمت المعالجة:** تعليم البلاغ كمنجز ليتم تحديث الإحصائيات والخريطة والشارتات فوراً.
   - **🗑️ حذف البلاغ:** إزالة البلاغ غير الصحيح من السجل.
   - **💾 الحفظ التلقائي:** تخزين البيانات محلياً في المتصفح (`localStorage`) للحفاظ على التعديلات.

4. **📈 لوحات ومؤشرات قياس فورية (Real-Time KPIs & Analytics):**
   - شارت التوزيع الزمني للبلاغات المعلقة ونسبة البلاغات التي تجاوزت مهلة الشهرين (60 يوماً).
   - شارت توزيع البلاغات حسب مدراء البرامج والاستشاري المشرف.
   - شارت المقاولين المتأخرين.

5. **🖨️ تصدير وطباعة تقارير احترافية:**
   - **طباعة جدول البلاغات المعلقة PDF:** طباعة جدول نظيف ومنسق بالألوان الرسمية الستة.
   - **إنفوجرافيك تنفيذي A4 (`infographic_report.html`):** تقرير قيادي مصمم للطباعة على صفحة A4 واحدة.
   - **تصدير إكسيل ديناميكي:** تنزيل قاعدة البيانات المحدثة بضغطة زر.

## 🚀 كيفية الربط والرفع على مستودع GitHub

لربط المشروع بمستودع GitHub الخاص بك (`https://github.com/abuahad2000/A.NWC`) ورفع أحدث نسخة:

```bash

# 2. إضافة جميع الملفات

# 3. حفظ الالتزام

# 5. ربط المستودع البعيد

git push -u origin main
```

## ⚖️ معايير حوكمة البلاغات وقواعد التدقيق

1. **حالة البلاغ:** يُعتمد فقط البلاغات قيد الإجراء (`تحت معالجة المقاول` أو `بانتظار اعتماد الجهة المتعدية`).
2. **المطابقة المكانية والتعاقدية الصارمة:**
   - **مدينة الرياض:** مطابقة إحداثيات البلاغ جغرافياً داخل مضلع KMZ للمشروع الجاري + تطابق اسم المقاول المنفذ.
   - **مشاريع المحافظات:** مطابقة نطاق المحافظة واسم المقاول مع بطاقة المشروع الجاري للمحافظة.
   - **مشاريع المتفرقات (م. عبدالله الأسود):** تشمل المقاولين الخمسة المعتمدين على مستوى المدينة.
3. **استبعاد التشغيل والصيانة (O&M):** لا يتم قبول بلاغات عقود التشغيل والصيانة خارج نطاق المشاريع الرأسمالية الجارية.
